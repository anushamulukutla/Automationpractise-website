QA Practice App

A local playground for UI and API test automation. Every interactive element has a stable data-testid; pages marked tricky add dynamic IDs and delays.

Practice pages

  • Alerts and Dialogs: JS dialogs, modal, toasts, cookie banner
  • Iframes: single, nested, dynamic, dynamic ID, sandboxed
  • Windows and Tabs: new tab, popup, multiple tabs, child-to-parent data, redirects
  • Dropdowns and Selects: native, custom, dependent, autocomplete, delayed
  • Dynamic Elements: random ids, delays, spinners, infinite scroll, stale elements
  • File Upload and Download: single, multiple, drag and drop, progress, validation, downloads
  • Forms and Validation: registration form, inline validation, wizard
  • Tables and Pagination: sort, filter, page, select, expand, edit
  • Mouse and Keyboard: hover, right-click, drag and drop, shortcuts
  • Auth and Sessions: login states, JWT, timeout, protected page, storage viewer
  • Advanced: shadow DOM, canvas, SVG, permissions, basic auth, console errors
  • REST API: CRUD, JWT, pagination, /slow, /flaky, Swagger docs

Tools

  • Test Data: generate, export and import data; sample upload files
  • Settings: slow network, flaky mode, randomize IDs, reset
  • /health: service health endpoint
